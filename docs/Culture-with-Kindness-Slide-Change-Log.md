## Reconstruction note (material limitations)

No editable PowerPoint source was supplied, so the deck was reconstructed from the PDF with the original slide count, sequence, branding, photography and layout preserved:

- Slides 2–8 use the original background artwork (photography, Clean Break logo, mint cards, page numbers) with edited text re-set as editable text.
- Slides 9–11 are the original screenshot designs; their text is not selectable in the source PDF, so it is preserved in the artwork and only the lines named in the brief were re-set as editable text.
- Slides 1 and 12 are unchanged and remain full-page original artwork.
- The original typeface, **Circular Std, is not available**; **DM Sans** is used as the closest geometric substitute. Sizes and positions follow the original proportions.
- Text is 10% smaller in absolute point size only because the reconstruction canvas is 1280 x 720 instead of 1440 x 810; relative to the slide it matches the original.

**Text fit check (visual, 12/12 pages):** no clipping, no overflow outside the canvas, headings and body copy legible at 1280 x 720, page numbers and original photography intact. One duplication was corrected: the source bullets on slide 6 were already part of the artwork, so the reconstructed list no longer draws a second bullet.
